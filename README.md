# 🌤️ Weather App

A simple and responsive weather application built using **HTML, CSS, and JavaScript** — no frameworks, no libraries.

## Features
- 🔍 Search weather by city name
- 🌡️ Real-time temperature, humidity, and wind speed
- ⛅ Dynamic weather conditions with icons
- 📱 Fully responsive design for mobile and desktop
- ⚠️ Graceful error handling for invalid city names

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript (Fetch API)
- [Open-Meteo API](https://open-meteo.com/) (free, no API key required)

## How to Run
1. Clone this repository
2. Open `index.html` in your browser
3. Search for any city and see live weather data!

## Files
- `index.html` — App structure
- `style.css` — Styling
- `script.js` — Weather fetching logic
